# SP1 남은 구현 실행 계획

기준 `0baa42c`. 순서: **기능 구현 → UI/UX → 종합 검증**. 기존 Task 1~12 번호는 유지한다. 독립 리뷰·서브에이전트·단계별 프리뷰 생성 없음. [공유 리뷰 원장](../../reviews/REVIEW_LEDGER.md)의 REV-008/013/016/017/018 경계를 유지한다.

## 1. T9-A — 업데이트 정리 상태·복구 기반 (이번 착수)

구현 상태: 로컬 진단 프로브/설명 카드, 네이티브 서비스 플랫폼, 서비스별 내구 기록·중지/독립 복구 워크플로, 복구 전용 어댑터/기존 기록 UI 연결 구현. 후속 T9-B에서 실제 조치에 연결했다. 컴파일만 확인했고 동작 검증은 T12에 남는다.

- 로컬 WUA 설치 진행/재부팅 대기와 wuauserv·BITS 서비스 상태를 각각 수집. false/Stopped만으로 업데이트 전체가 유휴라고 판정하지 않는다. 실패한 값은 확인 불가로 남긴다.
- 네이티브 서비스 API에 이름 허용 목록·상태 비교·정지 완료 관측·취소/시간 초과를 구현. 종속 서비스를 추가로 멈추거나 시작 유형을 변경하지 않는다.
- 중지 전 서비스별 원상태를 기존 내구 저장소에 저장. 첫 서비스만 멈춘 실패도 개별 복구 가능해야 한다. 원래 Stopped는 시작하지 않는다.
- 취소와 별개인 복구 기한, 서비스별 실패 보존, 다음 실행 기록 확인/선택 복구를 구현한다. 실제 서비스 중지·재시작 시험은 하지 않는다.
- 이 단계는 Download 삭제 버튼을 켜지 않는다. 복구 엔진을 구현하는 것과 업데이트 작성자 배타성을 확보하는 것은 별도다.

## 2. T9-B — Windows Update Download 실행기

구현 상태: [실행 연결/제한/검증 이월](../../reviews/2026-09-27-update-download-implementation.md). 고정 Download 7일 경과 파일, 양 서비스 Running·BITS 0건·활동 확인 조건, 중지/복구·부분 결과/UI 연결 구현. 컴파일 확인만 완료, 실제 실행 검증 미실시.

- WUA 설치 상태 외 BITS 전송·서비스 재진입·CBS/재부팅 경계와 지원 조건 확정. 확인 불가/활동 중은 실행 전 거절.
- Windows 경로 API에서 고정한 SoftwareDistribution/Download만 대상. DataStore·Installer·WinSxS 제외.
- 미리보기 고정 파일 집합 → 서비스 원본 저장/정지 → 파일 집합 재대조 → 개별 삭제 → 원래 실행 서비스 복구 → 재검사.
- 공통 삭제 엔진/관문을 재사용하고 서비스 정지도 Started로 기록. 부분 처리와 복구 실패를 별도 표시.

## 3. T10-B — Steam·그래픽 캐시 실행

구현 상태: [Steam 선택 정리/그래픽 공식 안내](../../reviews/2026-09-27-steam-cleanup-and-graphics-guides.md). Steam 명시 선택·설정 재대조·AppID 아래 30일 경과 파일·프로세스 관문·실행/재검사 연결 구현. NVIDIA NV_Cache 추가 관측과 정확한 공식 링크 연결. 그래픽 작성자 유휴/설정·재부팅 검증 불가로 NVIDIA 직접 삭제는 미등록. 컴파일만 확인, 동작 시험은 T12 대기.

- Steam 라이브러리별 명시적 선택, 실행 중 Steam/게임·파일 사용 여부 관문과 재다운로드 영향을 정의.
- NVIDIA DX/GL·Direct3D는 각각 독립 대상. 읽기 전용 Program Files 예외를 삭제 정책에 복사하지 않는다. idle을 판정할 수 없는 공급자는 앱/Windows 공식 기능 연결을 유지한다.
- 공통 고정 파일 집합·직전 보호/링크/ID·부분 처리 적용. 실제 사용자 캐시를 개발 테스트로 지우지 않는다.

## 4. T6/T10 남은 지원 범위

- 시작 폴더 항목은 원본·복구·다른 앱 변경 식별을 먼저 구현. StartupApproved 미문서 바이너리는 OS 계약 근거 없이 쓰지 않는다. Run 등록 해제는 이미 지원.
- 버전별 Adobe/Resolve/CapCut 설정 리더 확장. 현재 수동 선택을 자동 탐지로 표현하지 않는다.

## 5. T11 — UI/UX

- 용량 확보/로그인 실행 줄이기/화면 설정 등 효과별 묶음, 실행 가능한 항목 우선, 확인 불가·미지원 이유 명시.
- 진단→항목 선택→실행 전 영향→결과·재검사/되돌리기의 문구와 동선을 통일한다.

## 6. T12 — 검증·통합 배포

- 앞선 두 배치의 미작성 회귀부터 작성. 전체 기본·Smoke·영향 있는 ToolSmoke, 실기/VM 서비스 복구·UAC·실제 로그인·화면 복구·앱 캐시 재생성.
- 실패 수정 뒤 단일 통합 배포본을 만든다. 현재 preview.6는 마지막 기존 배포본으로 보존하고 새 소스와 구분한다.
