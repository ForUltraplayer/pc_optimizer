## 남은 출시 검증과 제한

- 실제 일반 권한에서 미리보기→확인 취소→실행→재검사 전체 UI, UAC 승인/거부와 다른 SID, 키보드 탐색·DPI 전환. 가짜 권한 fixture와 렌더링을 실제 조작 검증으로 부르지 않는다.
- 별도 .NET 미설치 Windows PC. 런타임 포함 여부와 이 PC에서의 실행만 검증했다.
- 이 PC의 일반 PATH에는 Python이 없었다. pip 실제 명령 검증에는 이미 존재하는 Codex 번들 Python을 사용했으며 제품에 그 위치를 하드코딩하거나 포함하지 않았다.
- 정상 사용자 캐시를 실제로 비우지 않았다. 실제 도구 검증은 명시한 임시 fixture만 사용했다.
- 현재 사용자 프로필 밖 캐시는 자동 정리 미지원. 외부 도구가 파일을 변경하므로 앱의 검사와 실행 사이 동시 변경을 원자적으로 잠그지 못한다. 실행 중 다른 패키지 작업을 피해야 한다.
- 여러 버전/설치 방식의 Node/Python/SDK, OEM/모니터 환경은 추가 검증 필요. 도구가 없거나 경로를 확인할 수 없으면 실행하지 않는다.
- 기존 원장의 minor 중 구조 문자열 익명화 과치환, 경로 토큰화 경계, OneDrive 계정 키 전체 값 읽기, 일부 프로세스 종료 실패 경로 등은 전부 해결한 것이 아니다. 1차 자동 정리 범위 밖의 세부 항목까지 전체 무결함을 보증하지 않는다.
