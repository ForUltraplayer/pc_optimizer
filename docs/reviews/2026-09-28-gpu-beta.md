# GPU 직접 제어 · 0.0.2 Beta 1 구현 기록

기준 `626ac4a`, 사용자 요청: ReBAR/업스케일링 직접 제어를 이어서 구현하고 완료 후 0.0.2 베타로 push. 독립 리뷰·서브에이전트 없음. 이 문서는 구현자 자체 검증이며 기존 REV의 독립 검증 상태를 바꾸지 않는다.

## 구현

| 영역 | 변경 파일 | 동작 |
|---|---|---|
| 모델·닫힌 실행 계약 | Core `GpuOptions.cs`, `ActionModels.cs`; Probes `ActionCoordinator.cs`, `RollbackCodec.cs` | GPU 기능/대상/선택, 뒤에 추가한 ActionId, Full 사용자 범위, 원본 직렬화 |
| NVIDIA | `Actions/Advanced/NvidiaApi.cs`, `GpuPlatform.cs` | System32 NVAPI, DRS 프로필 On/Off/Auto, 영상 상태와 품질 분리, GPU PCI/버스+드라이버 대조 |
| AMD | `Actions/Advanced/AmdVideoPlatform.cs` | System32 ADLX, GPU PNP 해시 대상, 장치에 해당하는 WMI 드라이버 버전 대조, 공식 영상 On/Off, 참조 해제 |
| 변경·복구 | `GpuActionAdapter.cs`, `RestoreCoordinator.cs` | 관측한 대상만 준비, Pending 저장 후 실행, 실제 재조회, 충돌 거절, 원래 출처까지 복원 |
| UI | `GpuCardViewModel.cs`, `AdvancedViewModel.cs`, `AdvancedView.xaml`, App 등록·ActionPresentation·ActionCenterViewModel | 세 GPU 카드·대상 선택·조회·별도 확인, 복구 기록의 대상 표시, 실제 네이티브 읽기 종료까지 공통 관문 유지 |

- ReBAR: 구 설정 `0x000F00BA` Off=0/On=1, 새 `0x000BFA21` Off=0/Auto=1/On=2. 실제 GetSetting이 반환한 형식만 사용하며 드라이버 버전만으로 새 ID를 강제하지 않는다. 응용 프로그램이 없는 전역 프로필 제외. 크기 제한·CPU exclusion 등 다른 ReBAR 설정은 변경하지 않는다. BIOS 활성 상태는 조회·변경하지 않는다.
- ReBAR 복구: 사용자 override, 드라이버 predefined, 상위 프로필 상속을 구분한다. 기본값 복원/override 삭제 후 재조회한다. NVAPI SaveSettings는 DRS 세션 전체 저장이므로 외부 프로그램과 원자적 CAS를 보장하지 못한다. 쓰기 직전 별도 세션으로 재대조하지만 외부 NVIDIA 도구와 동시 변경은 피해야 한다.
- NVIDIA 영상: Get128바이트/Set64바이트 ABI. Enabled(offset16)와 flags(offset12), 품질 값(Get44/Set20)을 구분. 끄기는 품질을 보존한다. 현재 PC의 max5는 Auto, 수동1~4. 비공개 API이며 알 수 없는 구조·범위는 거절.
- AMD: IADLXSystem2 → Multimedia → VideoUpscale. Image Sharpening에 의한 무효화 조건을 표시하고 의존 옵션이나 선명도는 바꾸지 않는다. WMI PNP/드라이버를 정확히 대조하지 못하면 거절한다. ADLX 미래 major>2는 거절한다.
- 읽기는 워커로 수행한다. UI 45초 제한 뒤 늦은 결과는 폐기하며 실제 네이티브 호출이 끝나야 실행 관문이 해제된다. 별도 네이티브 worker 프로세스 격리는 아직 없으므로 호출이 영구 정지하면 앱을 다시 시작해야 한다.

## 자체 검증과 실패 이력

- Release 빌드 경고0/오류0. 기본 **1761/1761**(이전1725+신규36). 신규 실제 GPU 조회 Smoke **3/3**. 상세 TRX는 로컬 `tests/PcOptimizer.Tests/TestResults/beta-final.trx`.
- `GpuActionTests`: 원본 기록 선행/왕복, predefined·상속, 드라이버·외부 값·대상·세션 변경, 취소, 잘못된 값/JSON, 쓰기 실패·재조회 불일치, struct 크기·네이티브 필드 오프셋.
- `AmdVideoAbiTests`: 소유한 네이티브 vtable에서 GPU 목록/QueryInterface/영상 bool getter·setter 호출, 참조5개 해제·중간 실패 정리. **실제 AMD 장치 성공이 아니다.**
- `GpuViewTests`: 대상 변경 후 재관측, 선택만으로 무실행, 실패/주입 값 비활성, 타임아웃 후 관문 유지·늦은 결과 폐기, 440px 폭 100/150/200% 렌더. 로컬 `artifacts/gpu-ui/advanced-gpu-*.png` 시각 확인.
- 실제 조회: NVIDIA 616.56에서 ReBAR 프로필73개(구 ID), NVIDIA 영상 출력3개(켜짐·Auto5) 확인. AMD 인터페이스 없음은 지원 불가 안내로 반환. 실제 사용자 GPU 설정·레지스트리·재부팅 변경 없음.
- 최초 AMD 테스트의 `var` 다중 선언 컴파일 오류 수정 후 통과.
- 별도 **저장하지 않는 DRS 메모리 사본** 시험은 SetSetting에서 `-137 NVAPI_INVALID_USER_PRIVILEGE`로 실패했다. 권한 상승 재시도는 자동 승인 검토가 실제 드라이버 setter 호출 위험으로 거절했다. 우회하지 않았으며 해당 시험을 자동 Smoke에서 제거했다. 실제 SaveSettings·영상 setter·AMD setter 호출은 하지 않았다. 접근 거절은 사용자에게 GPU 권한 안내로 표시하도록 구현했다.
- 최종 명령: `dotnet test tests/PcOptimizer.Tests -c Release --no-restore --filter "Category!=Smoke&Category!=Online&Category!=ToolSmoke|FullyQualifiedName~GpuReadSmokeTests" --logger "trx;LogFileName=beta-final.trx"`.
- 기존 전체 Smoke/Online/ToolSmoke, 실제 GPU 적용·원복, 재부팅, UAC/다른 사용자, .NET 없는 PC는 재검증하지 않았다. 실제 장치 적용/복원은 **평가 대기**이며 베타 노트와 ZIP 안내에도 명시한다.
