# PC Optimizer 0.2.1

조치를 눌렀을 때 반응과 실행 확인이 잘 보이도록 개선했습니다. 이전 0.0.2 베타의 고급 기능을 포함하며, 베타 표기가 없는 일반 릴리즈로 제공합니다.

## 변경 내용

- 조치 실행 / 되돌리기에서 진행 상황·실행 확인·거절 이유·결과가 누른 카드 바로 아래에 표시됩니다.
- 카드 안에서 조치할 때 스크롤 위치를 유지합니다. 다른 작업을 선택해도 이전 카드의 결과를 확인할 수 있습니다.
- 되돌릴 수 있는 설정에는 완료 카드에 원복 확인 버튼을 표시합니다. 파일·캐시 정리는 되돌리기를 제공하지 않습니다.
- 추가 앱 파일 탐색 결과(커뮤니티 규칙)를 기본 표시하고 설명을 쉽게 바꿨습니다. 자동 삭제 범위를 늘리지는 않았습니다.
- 오래된 임시파일 정리는 기존처럼 대상 확인 후 별도 실행 확인을 거칩니다. 확인 화면의 위치를 개선했으며 삭제 기준은 그대로입니다.

## 설치 없이 실행

`PcOptimizer-v0.2.1-win-x64.zip`을 내려받아 압축을 풀고 `PcOptimizer.exe`를 실행하세요. Windows 11 x64용이며 .NET 런타임이 포함되어 있습니다. 기존 앱이 실행 중이면 종료한 뒤 새 폴더에서 실행하세요. 함께 제공하는 `.sha256` 파일로 ZIP 해시를 확인할 수 있습니다.

## 검증 범위

- Release 빌드 경고·오류 0, 기본 테스트 **1,767개 통과**.
- 실행 전 별도 확인, 거절 사유, 설정 원복, 지연 결과, 스크롤 위치 및 WPF 100/150/200% 렌더 검증.
- 이번 변경은 UI 중심이며 실제 파일 삭제·GPU 설정 변경 시험은 수행하지 않았습니다. GPU 적용·복원은 대역으로 검증했으며 실제 장치 시험은 남아 있습니다. NVIDIA 영상 제어는 비공개 드라이버 인터페이스를 사용하고 AMD 장치에서의 적용은 미검증입니다.
- 코드 서명은 제공하지 않습니다. 실기 UAC·다른 계정·.NET 미설치 PC와 모든 도구 조합의 검증은 남아 있습니다.
