# PC Optimizer 0.0.2 Beta 1

고급 탭에서 설정을 직접 바꾸고 원래 값으로 되돌릴 수 있습니다. 기존 진단·정리·도구함·스크롤 개선도 포함합니다.

## 추가 기능

- MPO 끄기/Windows 기본 동작, HAGS 및 Windows 게임 모드 변경·복원.
- NVIDIA 게임별 ReBAR On/Off. 새로운 설정 형식을 지원하는 프로필은 Auto도 제공하며, BIOS의 ReBAR 설정은 바꾸지 않습니다.
- NVIDIA RTX 영상 초고해상도 On/Off 및 지원되는 품질 1~4/Auto 선택.
- AMD 공식 ADLX 동영상 업스케일링 On/Off. 선명도·RSR·가상 초고해상도는 변경하지 않습니다.
- BIOS/UEFI 또는 고급 시작 화면으로 재부팅. 실행 뒤 앱 안에서 5초간 취소할 수 있으며, 안전 모드는 고급 시작 화면에서 직접 선택합니다.

**사용법:** 고급 → 지원 대상 찾기 → 게임/GPU 선택 및 상태 읽기 → 바꿀 값 선택 → 적용 확인 → 실행. 되돌리기는 ‘조치 실행·되돌리기’의 기록에서 선택합니다.

## 베타의 검증 범위

Release 빌드와 기본 회귀·GPU 대역·화면 검증, 이 PC의 NVIDIA 상태 조회를 수행했습니다. 원본 기록 후 변경, 외부 변경/드라이버 교체 거절, 조회 지연 시 작업 관문 유지를 대역으로 검증했습니다.

**실제 GPU 쓰기·복원은 미검증**입니다. NVIDIA 영상 제어는 비공개 드라이버 인터페이스이며 버전에 따라 지원되지 않을 수 있습니다. AMD 장치가 없어 AMD 실기 확인도 남아 있습니다. UEFI/WinRE 실제 재부팅, 다른 계정 승격, .NET 없는 PC 확인도 미실시입니다. 성능 개선이나 모든 PC의 호환성을 보장하지 않습니다.

## 다운로드

`PcOptimizer-v0.0.2-beta.1-win-x64.zip`을 풀고 `PcOptimizer.exe`를 실행하세요. Windows 11 x64용이며 .NET 런타임이 포함돼 있습니다. 같은 이름의 `.sha256` 파일로 ZIP 해시를 확인할 수 있습니다. 코드 서명이 없는 평가판입니다.
