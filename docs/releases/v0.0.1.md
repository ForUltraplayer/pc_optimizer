# PC Optimizer 0.0.1

Windows 11 x64용 첫 공개 평가 버전입니다. 기존 preview.13 기능을 0.0.1 버전으로 묶었습니다.

## 다운로드 및 실행

`PcOptimizer-v0.0.1-win-x64.zip`을 내려받아 **압축을 모두 푼 뒤 `PcOptimizer.exe`를 실행**하세요. .NET 런타임이 포함되어 별도 설치가 필요하지 않습니다. 실행 시 관리자 권한 확인창이 나타납니다.

## 주요 기능

- 하드웨어·Windows 설정·드라이버·저장소·앱 캐시 진단과 설명
- 지원 캐시/시작 앱/전원 조치의 대상 확인, 선택 실행, 결과 및 지원 항목 복원
- Windows·제조사 공식 도구 연결, 문제 해결 도구함과 유틸리티 안내
- 탭별 스크롤 위치 기억, 중첩 목록 휠 연결, 대비를 높인 제목 표시줄·메뉴·본문

조치는 대상·영향을 확인하고 사용자가 선택한 경우에만 실행합니다. 캐시 삭제처럼 복원할 수 없는 작업도 있습니다. 지원 조건과 제한은 README를 확인하세요.

## 검증 및 알려진 제한

- 동일 기능의 preview.13 기준 Release 빌드 경고/오류 0, 기본 테스트 1,700개 통과. 이번 0.0.1 전환은 버전·배포 문서 변경이며 ZIP을 재빌드하고 패키지 구조·필수 고지·규칙 원문·해시를 검증했습니다.
- 실제 UAC/다른 계정, .NET 없는 PC, 장치별 DPI·터치패드, 일부 시스템 조치의 실기 평가는 남아 있습니다. 서명되지 않은 실행 파일이라 Windows에서 게시자를 확인할 수 없다는 안내가 나올 수 있습니다.
- ZIP의 SHA-256은 함께 첨부된 `.sha256` 파일에서 확인할 수 있습니다.
