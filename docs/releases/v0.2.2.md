# PC Optimizer 0.2.2

유틸리티 탭에 파일 검색·압축, 화면 캡처·녹화, 이미지 편집, 문서 작업 도구를 추가했습니다. 기존 0.2.1의 진단·조치·고급 기능을 포함하는 일반 릴리즈입니다.

## 변경 내용

- 퀘이사존 [「구독료 없이 쓰는 무료 프로그램 15선」](https://quasarzone.com/bbs/qc_plan/views/41399)의 본문 15개와 소개된 대안 6개를 반영했습니다. 기존 HWiNFO·CrystalDiskInfo를 재사용하고 19개를 추가해 유틸리티 외부 도구 카드는 총 34개입니다.
- 추가 도구: 반디집, 7-Zip, Everything, WizTree, WinDirStat, ShareX, PicPick, OBS Studio, VLC, 팟플레이어, GIMP, Paint.NET, XnConvert, PhotoCraft, Photon Studio, PowerToys, LibreOffice, Notepad++, Ditto.
- 카드에서 용도·사용법·주의사항을 확인하고 공식 다운로드 페이지를 바로 열 수 있습니다. 이 앱이 외부 도구를 자동 설치하거나 대신 실행하지는 않습니다.
- 개인·업무용 라이선스, 무료·유료 배포판 차이, 업로드·클립보드 기록·원본 덮어쓰기 등의 영향을 도구별로 안내합니다.
- 유틸리티 안내를 필요한 작업에 맞춰 도구를 선택하는 설명으로 바꿨습니다.

## 설치 없이 실행

`PcOptimizer-v0.2.2-win-x64.zip`을 내려받아 압축을 풀고 `PcOptimizer.exe`를 실행하세요. Windows 11 x64용이며 .NET 런타임이 포함되어 있습니다. 기존 앱이 실행 중이면 종료한 뒤 새 폴더에서 실행하세요. 함께 제공하는 `.sha256` 파일로 ZIP 해시를 확인할 수 있습니다.

## 검증 범위

- Release 빌드 경고·오류 0, 기본 테스트 **1,768개 통과**.
- 글의 21개 도구가 유틸리티에서 중복 없이 표시되고 카드 명령이 등록된 공식 링크를 요청하는지 확인했습니다. WPF 분류·카드·버튼·절차 배치를 포함합니다.
- 외부 프로그램의 실제 설치·동작과 모든 링크의 실제 사용자 브라우저 클릭은 검증하지 않았습니다. 웹 또는 브라우저로 공식 제품·배포 안내를 확인했으며 다운로드 파일의 서명·해시를 검증한 것은 아닙니다.
- 이번 변경에서 Smoke·Online·ToolSmoke와 실제 파일 정리·GPU 설정 변경 시험은 수행하지 않았습니다. 기존 GPU 쓰기·원복의 실제 장치 평가, 실기 UAC·다른 계정·.NET 미설치 PC 검증은 남아 있습니다.
- 코드 서명은 제공하지 않습니다. UAC·SmartScreen에 알 수 없는 게시자 또는 경고가 표시될 수 있습니다.
