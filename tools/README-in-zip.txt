PC Optimizer 실행 방법

1. 압축을 푼 폴더에서 PcOptimizer.exe를 더블클릭합니다.
2. 관리자 권한 확인창(사용자 계정 컨트롤)이 뜨면 "예"를 누릅니다.
3. 설치 과정은 없습니다. 삭제하려면 이 폴더를 지우면 됩니다.
4. 설정·로그 위치: %LocalAppData%\PcOptimizer
5. 문의할 때는 앱의 "내 PC 사양 → 이미지 저장"으로 만든 파일을 첨부해 주세요.

0.2.1 — Windows 11 x64

- 첫 화면에서 공간 확보 / 자동 실행 줄이기 / 전력·발열 조정을 선택합니다. 실행 전 대상·영향 확인 → 별도 실행 → 결과·재검사 순서입니다. 목록의 개수는 적용 가능 확정 수나 발견된 문제 수가 아닙니다.
- 사용자·Windows 임시 파일: 7일 이상 지난 일반 파일만 대상입니다. 사용 중인 파일·폴더는 남기며 휴지통을 거치지 않아 되돌릴 수 없습니다.
- npm·pip·NuGet HTTP: 설치·보호 조건을 통과한 공식 도구로 정리합니다. 다시 다운로드할 수 있으며 NuGet 설치 패키지는 제외합니다.
- 시작 앱: 현재 사용자 Run 및 모든 사용자 Run 32/64 등록을 항목별로 해제·복원합니다. 프로그램 삭제나 실행 중인 앱 종료는 하지 않습니다. 앱이 다시 등록하면 덮어쓰지 않습니다.
- 기본 시작 폴더의 지원되는 .lnk는 바로 위 Programs 폴더에 .PcOptimizer-disabled-…lnk.disabled로 보관합니다. 복구 기록과 보관 파일이 모두 있어야 원래 위치로 복원할 수 있습니다. 보관 파일을 지우거나 수정하지 마세요. 리디렉션 폴더·링크·대체 스트림·형식 불명은 지원하지 않습니다. 작업 관리자 토글 자체는 변경하지 않습니다.
- 전원 계획: 설치된 균형 조정·고성능·절전만 선택합니다. 고성능은 AC 연결이 필요합니다. 기록과 현재 상태가 맞으면 이전 계획으로 복원합니다.
- 주사율: 개선 후보 카드 또는 주사율 변경 창에서 같은 해상도의 지원 모드를 시험합니다. 15초 안에 유지하지 않으면 원복을 시도합니다. 강제 종료·전원 차단·드라이버 정지 중 원복은 보장하지 않으며 다음 실행에서 중단 기록을 확인하세요.
- 배달 최적화: 공식 Windows 제공자가 보고한 비고정 캐시 ID만 처리합니다. 활동 중이거나 상태를 확인할 수 없으면 진행하지 않습니다.
- Windows Update 다운로드 캐시: 고정 Download 폴더의 7일 이상 파일만 대상으로 합니다. wuauserv·BITS가 모두 실행 중이고 전송·설치·재시작 대기 등 검사 조건을 통과해야 합니다. 서비스 원상태 기록 → 중지 → 파일 처리 → 원래 실행 상태 복구를 수행합니다. 복구 실패는 파일 처리 결과와 별도로 표시하므로 변경 기록을 확인하세요. DataStore·Installer·WinSxS는 대상이 아닙니다.
- Adobe: 기본 및 직접 선택한 Media Cache Files / Peak Files의 90일 이상 .cfa·.pek만 정리합니다. 프로젝트·원본·DB·렌더 결과물은 제외하며 다음 편집 시 다시 만드는 시간이 필요합니다.
- Steam: 앱 캐시 위치 검사 뒤 라이브러리의 steamapps\shadercache를 직접 선택합니다. 현재 라이브러리 설정과 대조하고 Steam·게임을 닫은 상태에서 AppID 아래 30일 이상 파일만 대상으로 합니다. Program Files 등 보호 위치는 정리하지 않습니다. 다음 게임 실행 때 재다운로드·컴파일로 로딩과 끊김이 늘 수 있습니다.
- Resolve·CapCut: 기본/지원 설정 및 직접 지정한 CacheClip / Cache 폴더의 용량을 검사합니다. 읽기 전용이며 자동 삭제는 제공하지 않습니다. 모든 버전의 환경설정·프로젝트별 경로를 자동 탐지한 결과가 아닙니다.
- NVIDIA DXCache/GLCache/NV_Cache와 Direct3D는 용량 검사·공식 안내 연결입니다. 그래픽 앱의 사용 중 상태를 확정할 수 없어 직접 삭제하지 않습니다. Steam 다운로드 캐시도 공식 앱 절차로 안내합니다.
- 직접 선택한 캐시 위치는 이번 실행 동안만 유지합니다. 폴더를 선택하거나 공식 안내를 여는 것만으로 정리를 실행하거나 완료로 기록하지 않습니다.
- 다른 관리자 계정으로 승격하면 시스템 전용 범위가 되어 개인 캐시·개인 시작 항목·주사율 조치를 제공하지 않습니다.
- 자체 회귀·GUID 임시 파일 네이티브 시험·도구별 소유 임시 캐시 시험을 수행했습니다. 실제 UAC/다른 계정, 다음 로그인, 전원·화면 전환, 업데이트 서비스 중지·복구, 앱 캐시 재생성, .NET 없는 PC와 SmartScreen은 별도 평가가 남아 있습니다.
- 앱 폴더 삭제와 %LocalAppData%\PcOptimizer의 복구 기록 삭제는 별개입니다. 복구가 필요한 기록이 있으면 먼저 현재 상태를 확인하세요.

LICENSES 폴더: 사용한 오픈소스·규칙(winapp2)의 라이선스 고지
고급 탭:
- MPO·HAGS·게임 모드, NVIDIA 게임별 ReBAR·RTX 영상 초고해상도, AMD 동영상 업스케일링을 조회 후 선택하여 적용합니다. 변경 전 값은 ‘조치 실행·되돌리기’의 기록에 보관합니다.
- GPU ‘지원 대상 찾기’ → 대상 선택/상태 읽기 → 바꿀 값 → ‘적용 확인’ → 확인 화면의 실행 순서입니다. 대상·값 선택만으로 GPU 설정을 바꾸지 않습니다.
- ReBAR는 드라이버 게임 프로필만 변경하며 BIOS ReBAR를 켜지 않습니다. NVIDIA 영상 제어는 비공개 인터페이스를 사용합니다. 켜짐 표시는 영상이 실제로 처리 중이라는 뜻이 아닙니다.
- AMD 공식 ADLX 연동과 모든 GPU 적용/원복은 실제 장치에서의 추가 평가가 필요합니다. 개발 PC에서 NVIDIA 조회는 확인했고 GPU 쓰기는 대역으로만 검증했습니다. AMD 장치는 없었습니다.
- 드라이버·GPU 대상이 바뀌거나 외부에서 설정을 바꾸면 원복을 덮어쓰지 않습니다. 게임·재생기는 변경 전 종료하고 다시 실행해 효과를 확인하세요. 성능 향상을 보장하지 않습니다.
- UEFI/고급 시작 재부팅은 작업 저장 후 실행하세요. 앱 안에서 5초 취소 대기가 있습니다. 안전 모드는 재부팅한 고급 시작 화면에서 직접 선택하며 자동 직행하지 않습니다.
rules 폴더: 포함 규칙 원문(winapp2.ini 등, CC-BY-SA-4.0)과 출처 정보(sources.json). 앱은 실행 중 읽지 않음

이 실행 파일은 코드 서명이 없어 UAC에 '알 수 없는 게시자'나 SmartScreen 경고가 표시될 수 있습니다.
공식 배포처와 함께 제공된 SHA-256이 일치하는지 확인하세요. 출처나 파일이 의심되면 실행하지 마세요.
보안 경고를 모든 프로그램에 대해 끄지 마세요. 조직에서 실행을 막은 경우 관리자에게 문의하세요.

0.2.1 조치 화면 개선:
- 진행 상황·실행 확인·거절 이유·결과는 누른 카드 바로 아래에 표시합니다. 카드 내 조치 시 스크롤 위치를 유지합니다.
- 복원 가능한 설정만 완료 카드에서 되돌리기를 확인합니다. 파일·캐시 정리는 되돌릴 수 없으며 별도 실행 확인이 필요합니다.
- 추가 앱 파일 탐색 결과(커뮤니티 규칙)는 기본 표시합니다. 관측된 파일 크기가 안전하게 지울 수 있는 용량이라는 뜻은 아닙니다.
