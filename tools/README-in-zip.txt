PC Optimizer 실행 방법

1. 압축을 푼 폴더에서 PcOptimizer.exe를 더블클릭합니다.
2. 관리자 권한 확인창(사용자 계정 컨트롤)이 뜨면 "예"를 누릅니다.
3. 설치 과정은 없습니다. 삭제하려면 이 폴더를 지우면 됩니다.
4. 설정·로그 위치: %LocalAppData%\PcOptimizer
5. 문의할 때는 앱의 "내 PC 사양 → 이미지 저장"으로 만든 파일을 첨부해 주세요.

0.3.0-preview.6 — SP1 평가 빌드

- 첫 화면의 "개선할 작업 선택 · 결과 · 되돌리기"에서 대상과 영향을 확인한 뒤 실행합니다.
- "앱 캐시 위치·용량"에서 영상 편집 앱과 Steam·그래픽 캐시 결과로 이동합니다. Steam은 라이브러리별 shadercache, NVIDIA·Direct3D는 기본 캐시별 크기와 확인하지 못한 위치를 표시합니다. 새 Steam/그래픽 자동 삭제는 제공하지 않습니다. Steam의 다운로드 캐시와 셰이더 캐시는 서로 다른 대상입니다.
- "전체 결과"에서 DaVinci Resolve·CapCut 캐시가 발견되면 용량과 "캐시 위치·정리 방법 보기"를 확인할 수 있습니다. Resolve는 지원하는 전역 설정의 CacheClip 또는 기본 위치, CapCut은 기본 User Data/Cache만 검사합니다. 새 두 앱의 자동 삭제는 제공하지 않으며 앱 자체 정리 방법을 안내합니다. 프로젝트별·버전별·사용자 지정 위치를 모두 확인한 결과는 아닙니다.
- Adobe 기본 Media Cache Files/Peak Files는 90일 이상 된 .cfa·.pek만 별도 확인 후 정리합니다. 편집 앱을 닫아야 하며 캐시 재생성 시간이 필요합니다. DB·프로젝트·옮겨진 위치는 제외합니다.
- 사용자/Windows 임시 파일: 7일 이상 지난 일반 파일만 대상이며 사용 중인 파일과 폴더는 남깁니다. 휴지통을 거치지 않아 되돌릴 수 없습니다.
- npm·pip·NuGet HTTP: 설치·보호 조건을 통과한 공식 도구로 정리합니다. 캐시 재다운로드가 필요할 수 있습니다. NuGet 설치 패키지는 대상이 아닙니다.
- 전원 계획: 설치된 균형 조정·고성능·절전만 선택합니다. 고성능은 AC 연결 필요. 기록과 현재 값이 맞으면 이전 계획으로 되돌릴 수 있습니다.
- 자동 미지원: 시작 앱 변경, Windows Update/배달 최적화 내부 캐시, Adobe·Steam·NVIDIA 폴더 직접 정리. Windows 설정 또는 앱 자체 기능으로 안내합니다.
- 주사율 개선 후보 카드의 "130Hz 시험 적용" 같은 버튼에서 해당 모니터와 주사율을 사전 확인합니다. 별도 실행 옵션은 필요 없습니다. 사전 검사 뒤 "확인한 내용 실행"을 누르면 시험이 시작됩니다.
- 15초 안에 "유지"를 눌러야 프로필에 저장하며, 유지하지 않으면 원래 주사율로 복원을 시도합니다. 창 닫기/앱 종료는 중단·원복이 끝날 때까지 기다립니다. 다른 관리자 계정으로 승격한 시스템 전용 범위에서는 제공하지 않습니다.
- "주사율 변경 · 되돌리기"에서 다른 주사율 후보와 기록을 확인할 수 있습니다. 단일 프로세스 강제 종료·전원 차단·드라이버 응답 정지 중 15초 원복은 보장하지 않습니다. 재실행 시 중단 기록을 확인하고 복구하세요. 장치 경로 또는 외부 설정이 달라지면 덮어쓰지 않으며 Windows 디스플레이 설정에서 직접 확인해야 합니다.
- 주사율 기능은 대역 테스트와 실제 모드 조회/CDS_TEST만 검증했습니다. 실제 화면 전환·유지·분리·재부팅 평가는 아직 완료하지 않았습니다.
- 실제 UAC/다른 계정, 전원 변경·복원, .NET 없는 PC와 SmartScreen 평가는 아직 완료하지 않았습니다. 정식 출시 완료본이 아닙니다.
- 앱 폴더 삭제와 %LocalAppData%\PcOptimizer의 복구 기록 삭제는 별개입니다. 복구가 필요한 기록이 있으면 먼저 현재 상태를 확인하세요.

공식 배포처와 함께 제공된 SHA-256이 일치하는지 확인하세요. 출처나 파일이 의심되면 실행하지 마세요.
