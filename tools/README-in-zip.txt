PC Optimizer 실행 방법

1. 압축을 푼 폴더에서 PcOptimizer.exe를 더블클릭합니다.
2. 관리자 권한 확인창(사용자 계정 컨트롤)이 뜨면 "예"를 누릅니다.
3. 설치 과정은 없습니다. 삭제하려면 이 폴더를 지우면 됩니다.
4. 설정·로그 위치: %LocalAppData%\PcOptimizer
5. 문의할 때는 앱의 "내 PC 사양 → 이미지 저장"으로 만든 파일을 첨부해 주세요.

LICENSES 폴더: 사용한 오픈소스·규칙(winapp2)의 라이선스 고지
rules 폴더: 포함 규칙의 출처 정보(sources.json, 앱은 실행 중 읽지 않음)
